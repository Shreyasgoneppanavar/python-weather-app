# Python Weather App

A simple and user-friendly **Weather Application** built using **Python and Flask**. Enter any city name, and the app fetches **real-time weather details** using an API. It displays temperature, humidity, wind speed, and sky conditions.

---

## Tech Stack
- **Python**
- **Flask**
- **HTML**
- **CSS**
- **Weather API**
- **dotenv** for environment variables

---

## Features
- 🌡️ **Temperature** display  
- 💧 **Humidity** information  
- 🌬️ **Wind Speed**  
- ☁️ **Sky Conditions** (Clear / Clouds / Rain etc.)  
- 📡 Live weather data fetched via API  
- 🔍 Search by city name

---

## 📦 How to Run the Project

### 1️⃣ Install required packages  
```bash
pip install flask requests python-dotenv
```

### 2️⃣ Add your API key  
Create a `.env` file in your project folder and add the following line:

API_KEY=your_api_key_here

Make sure to replace `your_api_key_here` with your actual weather API key.

### 3️⃣ Start the app  
Run the project using one of the following commands:

```bash
python app.py
```
OR
```bash
py app.py
```

### 4️⃣ Open in browser  
After running the app, open the following URL in your browser:
```
http://127.0.0.1:5000
```
